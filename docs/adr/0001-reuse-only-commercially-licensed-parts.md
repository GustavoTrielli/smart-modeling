# Reuse only parts whose licenses allow commercial use

smart-modeling is for its owner first but may be sold later, so every part we reuse (code, model weights, datasets, body models, size charts, APIs and their terms of service) must allow commercial use. This rules out some of the most relevant academic garment-AI code and body models, which are often released for non-commercial research use only. We accept that loss rather than build on something we would have to rip out before selling.
